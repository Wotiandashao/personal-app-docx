## 7. 操作步骤

### 7.1 建立隔离验收环境

1. 读取 T01 的完成证据，核对当前源码、基准图、临时备份和用户改动。确定浏览器版本、服务地址、端口及待验收版本，不混用不同来源的数据结果。
2. 默认使用 Chrome DevTools。使用独立浏览器配置或隔离会话准备样例数据，避免清空真实用户 `personalAppPrototype.v1`；首轮视觉截图使用默认餐次和两条当天任务。
3. 运行第 10 节 Node 语法检查，并在后台启动本地服务，记录本次启动进程的 PID；如 8765 端口被占用，选空闲端口并记录，不终止用户已有进程。保留原有直接打开 `index.html` 的方式用于后续离线检查。
4. 先完成 390×844、100% 缩放的主视口检查，再做适配与状态检查。需要截图的调试材料先放项目根 `TEMP/` 本次目录，最终选定图才进入成果目录。

### 7.2 明确日期截图分支

1. **默认分支：**不安装额外工具，使用真实运行日期；首页和待办按真实当天两项默认任务对照结构。验收记录明确与原图 2026-09-21 的日期差异为审核允许的例外。
2. **可选分支：**只有用户另行批准临时安装工具后，才在项目根 `TEMP/` 本次目录准备 Playwright 并确认其固定时钟能力，在页面脚本执行前固定到 2026-09-21。不能在加载后仅点击 21 日来声称复现图示默认任务，因为默认任务在启动时挂到 `todayKey`。
3. 不论使用哪条分支，都不修改原型业务日期、系统时间或真实用户数据。记录分支、浏览器时区、实际运行日期以及是否固定时钟。
4. 可选固定时钟未获授权不阻塞默认分支验收；固定日期复现项记录“未执行：未安装可选工具，采用审核允许的真实日期例外”，不能标记固定日期复现已通过。

### 7.3 五页视觉对照与校准

1. 将最新 PNG 按与页面相同的逻辑宽度比较，核对标题、日期、卡片、图片比例、分隔、留白、底栏和红色选中态。不同系统字体、照片细节和生成噪点不作为逐像素失败依据。
2. **首页：**标题下中文日期与星期；白色待办卡含数量和右向查看全部；下一餐标题无 `↗`；午餐三图、名称、中文页脚和右向查看餐品；首页导航选中。
3. **点餐：**修改/完成文字操作、三餐标题与小红加号、每餐三列卡片及标签，无编号和深边框。严格沿用审核版 5.3：早餐、午餐完整；晚餐标题和图片可见，名称允许略低于导航上沿，但滚动后完整可达。不能为使首屏全显而缩字或压缩 44px 点击区。
4. **选餐：**返回入口为线性 `‹` 图标加文字，标题居中；白色餐次条和红短线；主食选中，五分类齐全；右白卡四个主食行、同排加号；无主导航或底部口号。
5. **待办：**白色日历、统一无衬线日期、黑月份灰箭头、红圆选中；白色任务输入、日期数量行与任务白卡；日历和任务自然增高。
6. **我的：**普通圆形头像、昵称与两条信息行、遮罩手机号；独立白色退出卡、红色文案；无旧英文、贴纸、海报和外跳箭头。
7. 检查字体统一，包含日期、手机号、页脚、数量和按钮；保留全局栈中的 Arial 回退，不允许旧局部等宽或装饰字体覆盖。检查窄屏与重绘不重新出现旧样式。
8. 必要修正只落在 T01 已审核的三个源码展示范围；记录问题与差异，修正后重跑对应页面和共享组件受影响项。业务或总体方案变化先返回计划审核，不顺手实现。

### 7.5 适配、离线与边界核对

1. DevTools 设备模拟依次设为 360×800、390×844、430×932、390×600，使用 100% 缩放检查五页。观察最底项、加号、选餐标题、七列日历、六周日历、长任务和超过三项餐品是否完整可达。
2. 使用浏览器页面缩放 **150%** 检查文本和操作，不以浏览器“字体大小”设置代替；记录缩放后的视口和变化。允许自然换行和滚动，不允许横向溢出、内容被固定导航永久遮挡或按钮不可点击。
3. 键盘遍历主要操作和弹窗，检查可见焦点；检查上下安全区的留白。用 Rendering 面板模拟 `prefers-reduced-motion`，确认减少动效规则生效。已排除的两项读屏问题只作已知范围记录，不新增修复。
4. 离线检查分两步，不在 http 来源下使用 DevTools Offline：该模式也会拦截 `127.0.0.1` 请求，未缓存的食物图片会加载失败，造成“存在远程依赖”的误判。
   - 在线状态下打开 Network 面板并勾选 Disable cache，遍历五页和全部分类，确认所有请求均指向 `127.0.0.1` 本地服务，没有其他主机。
   - 断开网络后，以 `file:` 方式直接打开 `index.html`，走一遍五页导航、添加餐品、添加任务和退出弹窗，确认资源与主要流程可用。
5. 对本次改动差异及图像哈希复核，确保未覆盖五张输入图、9 张食物、头像或旧参考图；无未审核功能和新增运行依赖。
