## 2. 目标与边界

### 2.1 目标

在保留 v1.0.0 业务内核、Hash 路由、本地存储结构和离线运行方式的前提下，将五页交互原型改造成“蓝调独立志”视觉。完成后，首页、点餐、选餐、待办、我的及其默认态、编辑态、完成态、空态、错误态、Toast 和退出弹窗均可操作，并具备进入全量回归的稳定候选版本。

### 2.2 包含内容

- 建立 `feature/ui-redesign-v1.0.0` 分支和可核验的实施前文件基线。
- 从现有参考图提取九种餐品图片和现有头像，改为独立本地资源。
- 修改 `index.html`、`styles.css`、`app.js` 的展示层结构、样式、动态标记和 ARIA 状态。
- 落实 `UIR-01` 至 `UIR-04`、`C-01` 至 `C-12`、五页需求和 `UI-STATES`。
- 检查 360、390、430px、360×640 短屏、200% 字号和减少动效下的基础可用性。
- 保持 `personalAppPrototype.v1`、现有数据结构、默认演示数据、页面 Hash、核心事件流程和 `file://` 离线能力。

### 2.3 不包含内容

- 不导出或覆盖五张正式静态原型图，不同步 `assets/reference`，不修改 PRD；这些工作由执行计划 02 负责。
- 不新增搜索、热量、份量、提醒、优先级、任务编辑或删除、账号、支付、后端、云同步等业务功能。
- 不引入外部字体、CDN、远程图片、构建工具或运行时网络请求。
- 不提交、合并分支或打标签，除非执行时另有明确授权。

## 3. 成功标准

- 五页视觉均使用深蓝外壳、纸白内容区、蓝白边缘、黄色选中态和低强度粉色装饰，不残留原有大圆角亮蓝卡片体系。
- 原有元素 ID、`data-*`、页面 Hash、存储键和核心业务流程保持兼容。
- 九种餐品和现有头像均由独立本地 PNG 提供，缺图时中文名称和操作仍可用。
- 五页核心路径在 360、390、430px 和 360×640 下无横向滚动、关键控件遮挡或不可达问题。
- T-009 的阶段检查无 P0 阻塞，才能交接执行计划 02。
